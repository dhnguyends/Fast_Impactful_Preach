FastImpact Preach — Eglise Evangélique Internationale de Genève (EEIG GVA)
================================================================================

FRANÇAIS
--------
FastImpact Preach est un outil interne de l'équipe média de l'EEIG GVA. Il transforme les
prédications enregistrées en courtes vidéos verticales. Il est fourni tel quel, sans garantie.

Vos données restent sur cet ordinateur, dans %LOCALAPPDATA%\FastImpactPreach (projets, clés API,
journaux). Les transcriptions des prédications sont envoyées à l'API Claude d'Anthropic pour choisir
les passages, avec votre propre clé API. La désinstallation conserve ce dossier.

ENGLISH
-------
FastImpact Preach is an internal tool of the EEIG GVA media team. It turns recorded sermons into
short vertical videos. It is provided as is, without warranty.

Your data stays on this computer, in %LOCALAPPDATA%\FastImpactPreach (projects, API keys, logs).
Sermon transcripts are sent to Anthropic's Claude API to choose passages, with your own API key.
Uninstalling keeps that folder.
